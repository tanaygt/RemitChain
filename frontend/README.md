## Levels Summary

- **Level 1 — White Belt**: Core XLM payments and wallet connection.
- **Level 2 — Yellow Belt**: Multi-wallet support and Soroban contract registry.
- **Level 3 — Orange Belt**: Performance caching, loading indicators, and testing.
- **Level 4 — Green Belt**: Inter-contract calls, CI/CD, and mobile responsiveness.

## Local Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
